# Implementation Plan: Code Coverage Reporting

**Branch**: `064-code-coverage` | **Date**: 2026-05-02 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/064-code-coverage/spec.md`

## Summary

Add working code coverage reporting to the backend and frontend workspaces, and wire a root-level convenience command. The backend already has coverage infrastructure (`@vitest/coverage-v8`, a `coverage` block in `vitest.config.ts`, and a `test:coverage` script) but is missing `all: true` to include zero-coverage source files. The frontend has `@vitest/coverage-v8` installed but its `vitest.config.ts` has no `coverage` block and `package.json` has no `test:coverage` script. The root `package.json` needs a `test:coverage` script to run both workspaces in sequence.
